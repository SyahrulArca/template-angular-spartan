# Kamus Istilah Penting Angular (Angular Glossary)

Dokumen ini berisi daftar istilah kunci yang sering digunakan dalam ekosistem **Angular**, lengkap dengan penjelasan, contoh kasus penggunaan, fitur Angular terkait, serta catatan penting.

---

## 📌 Rekomendasi Kolom Tambahan

Untuk memperkaya kamus istilah ini dan mempermudah proses belajar/referensi, berikut adalah beberapa kolom tambahan yang disertakan dalam tabel:

1. **Kategori / Layer**: Mengelompokkan istilah berdasarkan ranah arsitektur (misal: _Core_, _Routing_, _State Management_, _Reactive Programming_).
2. **Tingkat Kesulitan**: Memberikan gambaran seberapa kompleks konsep tersebut (_Basic_, _Intermediate_, _Advanced_).
3. **Best Practice / Catatan**: Tips singkat atau peringatan saat mengimplementasikan istilah/konsep tersebut di proyek nyata.

| **Interceptor**               | HTTP           | Fitur untuk mencegat (_intercept_) dan memodifikasi HTTP Request atau Response secara global.                                 | Menambahkan _Bearer Token_ di header setiap request API atau menangani error HTTP `401 Unauthorized` secara global. | `HttpInterceptorFn`, `provideHttpClient(withInterceptors([...]))`                                                            |      Intermediate       | Gunakan _functional interceptors_ untuk implementasi yang lebih fleksibel dan minim _boilerplate_.                       |

## 💡 Ringkasan Rekomendasi Fitur Terkini (Angular Modern / v17+)

Bila Anda sedang membangun proyek baru, prioritaskan penggunaan fitur-fitur modern Angular berikut:

- **Standalone Components** menggantikan `NgModule`.
- **Built-in Control Flow** (`@if`, `@for`, `@switch`) menggantikan `*ngIf` dan `*ngFor`.
- **Signals** (`signal()`, `computed()`) menggantikan `BehaviorSubject` sederhana.
- **Functional Guards & Interceptors** menggantikan Class-based Guards/Interceptors.
- **Deferrable Views** (`@defer`) untuk kemudahan _lazy-loading_ komponen visual.
